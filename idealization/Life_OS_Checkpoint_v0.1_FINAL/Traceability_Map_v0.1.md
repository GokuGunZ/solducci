## C. Case Study -> Insight -> Rationale / Design consequence

- **Solducci** -> Project identity, progressive feature structure, generic-vs-contextual knowledge, Idea body -> R02/R03/R04; DP04/DP15/DP16.
- **LaGenteStrana** -> collaborative evolving Project, entrepreneurial execution, project discovering its own missing capabilities -> Project identity + progressive decomposition.
- **Agrivoltaico** -> exploration under uncertainty, scenario/knowledge-gap/commitment threshold, long parking -> Intentionality model + inactivity/importance signals.
- **HistoryExplorer** -> lightweight collaboration/delegation and cross-project learning synergy -> low-friction project identity + SR10.
- **Speedcubing** -> Session sampling, Metric, Observation, Practice, knowledge composition, derived progress -> R05, DP11/DP17, Time/Experience model.
- **Crochet** -> inspiration as link, Idea->Project, artifact, reusable Pattern/Knowledge -> progressive structuring + DP13/DP16.
- **Values reflection examples** -> Self/Values/Resonance, system-as-mirror, revisable identity -> R08/R09, DP01/DP10/DP20.

## D. Requirement -> Principle examples

- **Resume (SR06)** -> DP04 progressive structuring, DP05 maturity, DP07 views, DP12 near-term detail, DP16 reusable past work.
- **Planned vs actual (SR13)** -> DP01 mirror, DP03 reality check, DP10 revisable self-model, DP11 useful measurement.
- **Knowledge reuse (SR15)** -> DP06 derivation, DP15 contextual truth, DP16 past work reduces future work.
- **Life maintenance visibility (SR17)** -> DP02 rails, DP08 cost-aware formalization, DP20 autonomy over optimization.
- **Idea preservation (SR04)** -> DP04 progressive structuring, DP13 user-controlled promotion, DP18 emergence before taxonomy.

## E. Ontology handoff chain

`Real friction / SR` -> `Case Study` -> `Model mechanism` -> `Rationale` -> `Decision / Open Question` -> `Ontology construct candidate`.

The next cycle should reject any ontology construct that cannot be traced back to a real requirement/case or that violates the checkpoint design principles.
